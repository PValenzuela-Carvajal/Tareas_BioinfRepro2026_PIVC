# Scipt Ejercicio 2.3 

This folder contains the scripts used for the Stacks analysis. 

Scripts
 * 1.1 `Alignment_Script.sh` — Sequence alignment.
 * 1.2 `pstacks.sh` — Construction of loci using pstacks.
 * 1.3 `build_catalogs.sh` — Construction of the catalog.
 * `1.4 sstacks.sh` — Matching samples against the catalog.
 * `1.5 populations_statistics.sh` — Population-level statistics.
 * `1. Master_script_stacks.sh` — Master script to run the analysis.

1.Master_script_stacks.sh — Combines the individual steps (Scripts 1.1 to 1.5) into a single script to facilitate the execution of the complete workflow.
