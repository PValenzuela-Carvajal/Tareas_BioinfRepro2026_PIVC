# Scipt Ejercicio 2.3 

This folder contains the scripts used for the Stacks analysis. 

Scripts
1.1Alignment_Script.sh — Sequence alignment.
1.2pstacks.sh — Construction of loci using pstacks.
1.3build_catalogs.sh — Construction of the catalog.
1.4sstacks.sh — Matching samples against the catalog.
1.5populations_statistics.sh — Population-level statistics.
1.Master_script_stacks.sh — Master script to run the analysis.

1.Master_script_stacks.sh — Combines the individual steps (Scripts 1.1 to 1.5) into a single script to facilitate the execution of the complete workflow.
