# R for Bioinformatics — Unit 1.3 Exercises

This repository contains the completed exercises from **Unit 3: Introduction to R with a Bioinformatics Approach**.

## Contents

- **`ejercicios.qmd`** — Quarto source file containing all the exercises (1–9) from the unit, including the code, comments, and explanations for each one.
- **`ejercicios.html`** — Rendered HTML report with the outputs and results of every exercise.

## About the Exercises

The exercises cover the core topics of the unit:

1. Creating variables and using basic functions (`log`, `sum`, etc.)
2. Vector operations
3. Matrices and data frames
4. Loading data files into R
5. `for` loops (including `next` and storing results)
6. Reading and understanding an existing R script (IBR/Mantel test analysis)
7. Writing custom functions (`calc.tetha`)
8. Partial Mantel tests with the `vegan` package
9. Data exploration and manipulation with a real dataset
10. Exploring CRAN and Bioconductor packages

All exercises were completed and are documented in the `.qmd` file. The final results can be viewed in the rendered `.html` report.

## How to Use

- Open `ejercicios.qmd` in RStudio to review or re-run the code.
- Open `ejercicios.html` in any web browser to see the full report with outputs.

## Conclusion

Working through these exercises provided a hands-on introduction to R with a bioinformatics focus. From basic syntax and data structures to loops, custom functions, and package management, each exercise reinforced the fundamentals needed for reproducible analysis.
